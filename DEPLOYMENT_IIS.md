# Local IIS Deployment Guide

This guide is included for the Deliverable 3 local IIS deployment requirement.

## 1. Install IIS prerequisites

1. Open **Turn Windows features on or off**.
2. Enable **Internet Information Services**.
3. Under **Web Management Tools**, enable **IIS Management Console**.
4. Under **World Wide Web Services → Application Development Features**, enable the required ASP.NET-related features available on your Windows edition.
5. Install the **.NET 8 Hosting Bundle** from Microsoft's official .NET download page. Restart IIS after installation.

## 2. Prepare the database

The project uses SQL Server for both Identity and Books. The default connection string uses SQL Server LocalDB:

`Server=(localdb)\mssqllocaldb;Database=StudentBookExchangeDB;Trusted_Connection=True;MultipleActiveResultSets=true`

For a more reliable IIS setup, use a SQL Server / SQL Server Express instance and update `DefaultConnection` in the published `appsettings.json`, for example:

`Server=.\SQLEXPRESS;Database=StudentBookExchangeDB;Trusted_Connection=True;TrustServerCertificate=True;`

Run the existing EF Core migrations against the target database before publishing:

```powershell
Update-Database
```

The database must contain the `Books` table and the ASP.NET Core Identity tables (`AspNetUsers`, `AspNetRoles`, and related tables).

## 3. Publish from Visual Studio

1. Open the solution in Visual Studio.
2. Right-click the web project and select **Publish**.
3. Select **Folder** as the target.
4. Choose a folder such as `C:\Publish\StudentBookExchange`.
5. Set the configuration to **Release**.
6. Click **Publish**.

The publish output contains the application files and the IIS `web.config` generated by the ASP.NET Core Web SDK.

## 4. Create the IIS website

1. Open **IIS Manager**.
2. Right-click **Sites → Add Website**.
3. Set the site name to `StudentBookExchange`.
4. Set the physical path to `C:\Publish\StudentBookExchange`.
5. Choose an unused port, for example `8085`.
6. Start the website.
7. If the site cannot access the database, grant the IIS application-pool identity the required SQL Server permissions or use an appropriate SQL login in the connection string.

Browse to:

`http://localhost:8085`

## 5. Verify the deployment

- Open the home page.
- Register a Student account and log in.
- Add a book listing.
- Search for it on Browse Books (jQuery AJAX).
- Open a second browser window and verify that SignalR refreshes the listing after a change.
- Sign in with the seeded Admin account and check the Admin dashboard and User Management page.

## Notes

- The LocalDB connection string is tied to the Windows user/machine. It may need to be changed for IIS.
- Do not publish real passwords or production connection secrets in source control.
- If using LocalDB under IIS, the application pool identity and user-profile settings can require extra configuration. SQL Server Express is usually simpler for a local IIS demonstration.
